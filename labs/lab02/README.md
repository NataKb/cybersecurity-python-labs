## Завдання 2. Аналіз активності користувачів

Реалізовано CLI-утиліту для аналізу журналу активності у форматі CSV. Програма виявляє активність у позаробочий час, масові запити до критичних ресурсів і формує звіт у форматі JSON.

Вхідні дані: `data/data_v07/activity.csv`

Запуск (із папки `labs/lab02`):

```bash
python task2.py --activity-log data/data_v07/activity.csv --out-report report.json --log-file app.log
```
Аргументи командного рядка
--activity-log — обов'язковий аргумент. Вказує шлях до CSV-файлу з журналом активності користувачів.
--after-hours — необов'язковий прапорець. Вмикає режим відображення лише попереджень про активність у позаробочий час. У поточній реалізації приховує виведення масових запитів, але не виключає їх із аналізу.
--out-report — необов'язковий аргумент. Вказує шлях і назву JSON-файлу, у який зберігається звіт про результати аналізу.
--log-file — необов'язковий аргумент. Вказує шлях і назву файлу для збереження системних повідомлень і попереджень.
